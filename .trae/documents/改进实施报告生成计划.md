#### 第四章：遇到的问题及解决方案
基于会话摘要记录的实际问题：
1. **Conversation 软删除字段 is_active vs is_deleted**：计划用 is_deleted，实际模型用 is_active，测试中纠正
2. **PowerShell 不支持 &&**：使用 cwd 参数和 .cmd 扩展名
3. **Celery mock 策略**：importlib 直接加载模块绕过 __init__.py 导入链；shared_task mock 需支持两种装饰形式
4. **SQLAlchemy execute 参数位置**：params 是第二个位置参数(args[1])，非 kwargs
5. **测试 mock 更新**：Task #143 新增 searchKeyword/searchHistory 导致 DocumentItem.test 和 SearchBar.test 失败
6. **document.test.ts folder API 重写**：Task #137 从 Mock 改真实 API 后，测试需从状态验证改为 API 调用验证
7. **App.tsx HelpPage 导入遗漏**：Task #143 添加路由但遗漏 import，导致 tsc 编译失败
8. **D9-01 releaseCommand 缺失**：railway.json 仅有 healthcheckPath，缺少 releaseCommand

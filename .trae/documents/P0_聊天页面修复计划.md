### 后端接口（已就绪，只读参考）
- `POST /chat/ask` — 非流式问答，返回 `AnswerResponse`
- `POST /chat/ask/stream` — SSE 流式问答，事件类型 `sources`/`chunk`/`done`/`error`
- `GET /chat/conversations?page=&page_size=` — 对话列表分页
- `GET /chat/conversations/{id}` — 对话详情（含 messages 数组）
- `DELETE /chat/conversations/{id}` — 软删除对话（204）

### 后端 Schema 对齐参考（`backend/app/schemas/chat.py`）
- `QuestionRequest`: question(1-2000), conversation_id?(ge=1), stream(default false), idempotency_key?(1-100, `[a-zA-Z0-9_-]`)
- `SourceItem`: document_id?, title, content, score(0-1)
- `AnswerResponse`: answer, sources[], conversation_id, message_id?, degraded, degrade_reason?
- `MessageResponse`: id, role, content, sources?, created_at
- `ConversationResponse`: id, title, is_active, created_at, updated_at, messages[]
- `ConversationListResponse`: items[], total, page, page_size

### 步骤 1：创建类型定义 `frontend/src/types/chat.ts`

**作用**：定义聊天相关的 TypeScript 类型，对齐后端 `schemas/chat.py`。

**遵循模式**：参考 `types/document.ts` 的 JSDoc 注释 + interface 定义风格。

**内容**：
```typescript
/** SSE 流式事件类型 */
export type StreamChunkType = "sources" | "chunk" | "done" | "error";

/** 消息角色 */
export type MessageRole = "user" | "assistant";

/** 引用来源项（对齐后端 SourceItem Schema） */
export interface SourceItem {
  document_id?: number;
  title: string;
  content: string;
  score: number;
}

/** 提问请求（对齐后端 QuestionRequest Schema） */
export interface QuestionRequest {
  question: string;
  conversation_id?: number;
  stream?: boolean;
  idempotency_key?: string;
}

/** 回答响应（对齐后端 AnswerResponse Schema） */
export interface AnswerResponse {
  answer: string;
  sources: SourceItem[];
  conversation_id: number;
  message_id?: number;
  degraded: boolean;
  degrade_reason?: string;
}

/** 消息响应（对齐后端 MessageResponse Schema） */
export interface ChatMessage {
  id: number;
  role: MessageRole;
  content: string;
  sources?: SourceItem[] | null;
  created_at: string;
  is_degraded?: boolean;
  degrade_reason?: string;
}

/** 对话响应（对齐后端 ConversationResponse Schema） */
export interface Conversation {
  id: number;
  title: string;
  is_active: boolean;
  created_at: string;
  updated_at: string;
  messages?: ChatMessage[];
}

/** 对话列表响应（对齐后端 ConversationListResponse Schema） */
export interface ConversationListResponse {
  items: Conversation[];
  total: number;
  page: number;
  page_size: number;
}
```

### 步骤 2：创建 API 层 `frontend/src/api/chat.ts`

**作用**：封装聊天相关接口调用。

**遵循模式**：参考 `api/document.ts`，导入 `apiClient` + `API_PATHS` + 类型。

**内容**：
```typescript
import { apiClient, type StreamCallbacks } from "./client";
import { API_PATHS } from "@/utils/constants";
import type {
  QuestionRequest,
  AnswerResponse,
  Conversation,
  ConversationListResponse,
} from "@/types/chat";

/** 非流式提问 */
export async function ask(data: QuestionRequest): Promise<AnswerResponse> {
  return apiClient.post<AnswerResponse>(API_PATHS.CHAT_ASK, data);
}

/** 流式提问（SSE） */
export async function askStream(
  data: QuestionRequest,
  callbacks: StreamCallbacks,
  signal?: AbortSignal,
): Promise<void> {
  return apiClient.streamPost(API_PATHS.CHAT_ASK_STREAM, data, callbacks, signal);
}

/** 获取对话列表（分页） */
export async function getConversations(
  page = 1,
  pageSize = 20,
): Promise<ConversationListResponse> {
  const query = new URLSearchParams();
  query.set("page", String(page));
  query.set("page_size", String(pageSize));
  return apiClient.get<ConversationListResponse>(
    `${API_PATHS.CONVERSATIONS}?${query.toString()}`,
  );
}

/** 获取对话详情（含消息历史） */
export async function getConversationDetail(id: number): Promise<Conversation> {
  return apiClient.get<Conversation>(API_PATHS.CONVERSATION_DETAIL(id));
}

/** 删除对话（软删除） */
export async function deleteConversation(id: number): Promise<void> {
  await apiClient.delete(API_PATHS.CONVERSATION_DETAIL(id));
}
```

### 步骤 3：创建 Store `frontend/src/store/chatStore.ts`

**作用**：管理聊天状态——对话列表、当前对话、消息列表、流式输出状态、错误。

**遵循模式**：参考 `documentStore.ts` 的 Zustand `create` 模式；模块级变量管理 `AbortController`（仿 `pollingManager` 模式）。

**状态字段**：
- `conversations: Conversation[]` — 对话列表
- `currentConversationId: number | null` — 当前对话ID
- `messages: ChatMessage[]` — 当前对话的消息列表
- `streaming: boolean` — 是否正在流式输出
- `streamingContent: string` — 流式输出中累积的文本
- `streamingSources: SourceItem[]` — 流式输出中收到的引用来源
- `loadingConversations: boolean` — 对话列表加载中
- `loadingMessages: boolean` — 消息加载中
- `error: string | null`

**Actions**：
- `loadConversations()` — 加载对话列表
- `selectConversation(id)` — 选择对话，加载消息历史
- `startNewConversation()` — 开始新对话（清空当前对话和消息）
- `sendMessage(question)` — 发送消息（流式）：
  1. 立即追加用户消息到 messages
  2. 设置 streaming=true，streamingContent=""
  3. 生成 idempotency_key（`Date.now()-random` 格式，符合 `[a-zA-Z0-9_-]`）
  4. 创建 AbortController 存入模块级变量
  5. 调用 `askStream`，回调：
     - `onSources`: 设置 streamingSources
     - `onChunk`: 累加 streamingContent
     - `onDone`: 追加完整 assistant 消息到 messages，设置 currentConversationId（新对话时）
     - `onError`: Toast 错误提示
  6. finally: streaming=false，清空 streamingContent/streamingSources，释放 controller
- `stopStreaming()` — 取消流式输出（调用 AbortController.abort()）
- `removeConversation(id)` — 删除对话
- `clearError()`

**关键实现细节**：
- 模块级 `let streamingController: AbortController | null = null`
- `sendMessage` 中处理 `AbortError`（通过 `err.name === "AbortError"` 判断，仿 `documentStore.ts` 上传取消逻辑）
- 流式期间在前端显示一个临时的 assistant 消息（content = streamingContent，带 typing 指示器）
- `onDone` 后用完整回答替换临时消息

## 假设与决策

1. **流式优先**：聊天页面默认使用流式接口（`/chat/ask/stream`），提供打字机效果，非流式接口 `ask` 保留但不在 UI 使用
2. **idempotency_key 生成**：前端使用 `chat-${Date.now()}-${Math.random().toString(36).slice(2,8)}` 格式，符合后端 `[a-zA-Z0-9_-]` 正则
3. **新对话 ID 获取**：流式 `onDone` 回调不直接返回 conversation_id（后端在 sources/chunk/done 事件中不携带），因此新对话的 conversation_id 通过 `onDone` 后重新加载对话列表获取（列表按 updated_at 倒序，首项即新对话）；或更简单方案——不主动跳转 URL，新对话留在当前页，用户下次刷新时可见
4. **对话切换**：点击侧边栏对话项时导航到 `/chat/:conversationId`，页面读取参数后加载对话详情
5. **移动端**：侧边栏默认折叠，点击汉堡菜单展开（仿 DocumentsPage 模式）
6. **自动滚动**：使用 `useEffect` 监听 messages 和 streamingContent 变化，滚动消息容器到底部
7. **导航集成**：在文档页 Sidebar 和聊天页 ChatSidebar 都添加双向导航链接（知识库管理 ↔ 问答对话）
8. **降级提示**：degraded=true 的 AI 消息显示 warning Badge "降级回复"，点击可查看 degrade_reason

# 产品需求文档 (PRD) - GeiIt企业知识库前端

## 1. 产品概述

GeiIt企业知识库前端，为用户提供文档上传、管理、检索和预览的统一工作台。采用 Claude Code 风格的简洁现代界面，聚焦于高效文档管理和快速信息检索，面向企业内部知识沉淀与共享场景。

- **目标用户**: 企业员工（需管理员审批注册）、超级管理员
- **核心价值**: 统一文档入口、权限隔离的个人文档库、快速检索与预览
- **技术栈**: React 18 + TypeScript + Vite + Tailwind CSS + Zustand

## 2. 核心功能

### 2.1 用户角色

| 角色 | 注册方式 | 核心权限 |
|------|----------|----------|
| 普通用户 | 邮箱申请注册（需管理员审批） | 管理个人文档库、上传/预览/检索文档 |
| 超级管理员 | 系统预设 | 审批注册申请、管理公共文档库、访问所有文档 |

### 2.2 功能模块

1. **登录页**: 邮箱+密码登录、表单校验、注册申请入口
2. **注册申请页**: 填写邮箱+用户名提交申请，展示申请状态流程
3. **密码设置页**: 通过邮件链接设置初始密码
4. **文档管理页**: 文件上传（点击+拖拽）、文档库分支管理、文档列表、文档预览
5. **文档检索面板**: 实时搜索、多维度排序、筛选

### 2.3 页面详情

| 页面名称 | 模块名称 | 功能描述 |
|----------|----------|----------|
| 登录页 | 登录表单 | 邮箱+密码输入、实时校验、错误提示、登录跳转 |
| 登录页 | 注册入口 | 跳转注册申请页链接 |
| 注册申请页 | 申请表单 | 邮箱+用户名填写、提交申请 |
| 注册申请页 | 流程指引 | 展示申请→审批→设密码的流程步骤 |
| 密码设置页 | 密码设置 | 通过 token 链接设置密码、密码强度校验 |
| 文档管理页 | 侧边栏 | 文档库分支列表、新建分支、分支切换 |
| 文档管理页 | 上传区 | 点击上传+拖拽上传、文件类型校验、上传进度 |
| 文档管理页 | 文档列表 | 文件名/类型/大小/状态/时间展示、操作按钮 |
| 文档管理页 | 搜索排序栏 | 实时搜索框、排序下拉（时间/名称/类型+升降序） |
| 文档管理页 | 文档预览 | 点击文件在右侧面板预览内容（Markdown/PDF/TXT） |

## 3. 核心流程

### 3.1 用户注册审批流程

用户在注册申请页填写邮箱和用户名，提交后系统将申请发送至超级管理员邮箱。管理员审核通过后，系统向申请人邮箱发送密码设置链接，用户点击链接进入密码设置页完成密码设置，即可使用邮箱登录系统。

```mermaid
flowchart TD
    "用户填写注册申请" --> "提交申请(邮箱+用户名)"
    "提交申请(邮箱+用户名)" --> "系统通知管理员"
    "系统通知管理员" --> "管理员审核"
    "管理员审核" -->|"通过"| "系统发送密码设置链接至申请人邮箱"
    "管理员审核" -->|"拒绝"| "通知申请人审核未通过"
    "系统发送密码设置链接至申请人邮箱" --> "用户点击链接"
    "用户点击链接" --> "设置密码"
    "设置密码" --> "使用邮箱登录"
```

### 3.2 文档管理流程

用户登录后进入文档管理页，可在侧边栏选择或创建文档库分支。在选定分支内，通过点击或拖拽上传文件，系统显示上传进度和处理状态。文档列表支持实时搜索和多维度排序，点击文档可在预览面板查看内容。

```mermaid
flowchart TD
    "用户登录" --> "进入文档管理页"
    "进入文档管理页" --> "选择/创建文档库分支"
    "选择/创建文档库分支" --> "上传文档(点击或拖拽)"
    "上传文档(点击或拖拽)" --> "系统异步处理"
    "系统异步处理" --> "文档出现在列表中"
    "文档出现在列表中" --> "搜索/排序筛选"
    "搜索/排序筛选" --> "点击文档预览"
```

## 4. 用户界面设计

### 4.1 设计风格

- **设计参考**: Claude Code 网页风格 — 简洁、专业、注重内容可读性
- **主色调**: 暖白背景 (#FAFAF9) + 深炭灰文字 (#1A1A1A) + 橙色强调色 (#D97757)
- **辅助色**: 浅灰边框 (#E5E5E4)、灰阶层次 (#71717A / #A1A1AA)
- **按钮风格**: 圆角 (rounded-lg)、实色填充主按钮、边框次按钮
- **字体**: 系统字体栈 — `-apple-system, "Segoe UI", "Noto Sans SC", sans-serif`
- **布局**: 左侧固定侧边栏 + 右侧主内容区，桌面优先响应式
- **图标**: lucide-react 图标库
- **动画**: 微妙的 hover 过渡 (150ms ease)、页面切换淡入 (200ms)

### 4.2 页面设计概览

| 页面名称 | 模块名称 | UI 元素 |
|----------|----------|--------|
| 登录页 | 居中卡片 | 暖白背景、居中登录卡片、邮箱/密码输入框、橙色登录按钮、错误红色提示 |
| 注册申请页 | 居中卡片 | 邮箱/用户名输入、申请按钮、下方流程步骤指引（三步骤图标+文字） |
| 密码设置页 | 居中卡片 | 密码输入+确认密码、强度指示器、设置按钮 |
| 文档管理页 | 侧边栏 | 文档库分支列表、新建分支按钮、分支高亮选中态 |
| 文档管理页 | 顶栏 | 搜索框（左侧放大镜图标）、排序下拉、上传按钮 |
| 文档管理页 | 文档列表 | 卡片式/列表式文档项、文件类型图标、状态徽章、hover 阴影 |
| 文档管理页 | 上传区 | 虚线边框拖拽区、拖入高亮、上传进度条 |
| 文档管理页 | 预览面板 | 右侧滑出面板、Markdown 渲染、PDF 内嵌、TXT 直接显示 |

### 4.3 响应式设计

- **桌面端 (≥1024px)**: 侧边栏 (240px) + 主内容区 + 预览面板三栏布局
- **平板端 (768-1023px)**: 侧边栏可折叠 + 主内容区双栏，预览面板全屏覆盖
- **移动端 (<768px)**: 底部导航栏 + 单栏内容，上传/预览全屏模态

### 4.4 状态处理

- **加载状态**: 骨架屏 (skeleton) 占位、按钮 spinner
- **空状态**: 友好插画 + 引导文案 + 操作按钮
- **错误状态**: 红色错误卡片 + 重试按钮
- **上传进度**: 实时进度条 + 百分比 + 取消按钮

## 5. 后端 API 对接说明

### 5.1 已有接口（直接对接）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/auth/login` | POST | 用户名+密码登录，返回 access_token + refresh_token + user |
| `/api/v1/auth/register` | POST | 用户名+邮箱+密码注册 |
| `/api/v1/auth/refresh` | POST | 刷新 Token |
| `/api/v1/auth/logout` | POST | 登出（拉黑 Token） |
| `/api/v1/documents/upload` | POST | multipart/form-data 文件上传 |
| `/api/v1/documents` | GET | 文档列表（分页+状态筛选+范围选择） |
| `/api/v1/documents/{id}` | GET/DELETE | 文档详情/删除 |
| `/api/v1/documents/{id}/reprocess` | POST | 重新处理文档 |
| `/api/v1/documents/url` | POST | URL 导入 |
| `/api/v1/chat/ask` | POST | 非流式问答 |
| `/api/v1/chat/ask/stream` | POST | 流式问答 (SSE) |
| `/api/v1/chat/conversations` | GET | 对话列表（分页） |

### 5.2 需后端补充的接口（注册审批流程）

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/v1/auth/register/apply` | POST | 提交注册申请（邮箱+用户名） |
| `/api/v1/auth/register/status` | GET | 查询申请状态 |
| `/api/v1/auth/register/approve` | POST | 管理员审批（管理员权限） |
| `/api/v1/auth/set-password` | POST | 通过 token 设置密码 |
| `/api/v1/documents/folders` | GET/POST | 文档库分支管理 |
| `/api/v1/documents/folders/{id}` | PATCH/DELETE | 分支重命名/删除 |

> **注意**: 当前后端登录使用 `username` 字段，前端登录表单收集邮箱后将邮箱作为 username 传给后端（后端需支持邮箱登录，或前端增加用户名输入）。注册审批流程和文档库分支管理需要后端新增接口，前端先用 Mock 数据实现 UI，后端接口就绪后切换。

## 6. 技术约束

- **框架**: React 18 + TypeScript
- **构建工具**: Vite
- **样式方案**: Tailwind CSS 3
- **状态管理**: Zustand
- **路由**: React Router DOM v6
- **HTTP 请求**: fetch API + 自定义封装（拦截器、Token 刷新）
- **图标**: lucide-react
- **项目位置**: `kb_qa_system/frontend/`（与 backend 平级）

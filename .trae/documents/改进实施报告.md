### 3.4 安全性增强（4 项）

#### D3-01 CSP 内容安全策略（P2）

**改动内容**：修改 `frontend/nginx.conf`，添加 Content-Security-Policy header：
- `default-src 'self'`、`script-src 'self'`、`style-src 'self' 'unsafe-inline'`
- `img-src 'self' data: https:`、`connect-src 'self' https:`
- `frame-ancestors 'self'`、`base-uri 'self'`

**设计决策**：选择 CSP 而非 HttpOnly Cookie，因为 HttpOnly Cookie 需重构整个认证流程，CSP 能有效降低 XSS 风险且不破坏现有架构。

#### D3-02 /metrics 生产强制认证（P2）

- 创建 `frontend/src/config/env.ts`：集中管理前端环境变量，构建时校验必需变量

#### D10-03 数据保留策略 + 自动清理（P2）

### 4.2 PowerShell 不支持 && 操作符

**问题**：Windows PowerShell 执行策略阻止 .ps1 脚本，且不支持 `&&` 操作符连接命令。

**解决方案**：
- 使用 `.cmd` 扩展名调用工具（`npm.cmd`、`npx.cmd`）
- 避免 `&&`，改用 cwd 参数指定工作目录或用 `;` 分隔命令
- 使用 `tail`/`grep` 不可用时，改用 Read/Grep 工具

### 4.3 Celery mock 策略（测试隔离）

**问题**：运行 cleanup_tasks 测试时，`app/tasks/__init__.py` 导入 document_tasks → celery_app → celery（未安装），导致 `ModuleNotFoundError: No module named 'celery'`。

**解决方案**：
- 使用 `importlib.util.spec_from_file_location` 直接加载 cleanup_tasks.py，绕过 `__init__.py` 导入链

- `shared_task` mock 需支持两种装饰形式：`@shared_task` 和 `@shared_task(name=...)`

```python
def _shared_task(*args, **kwargs):
    if args and callable(args[0]):
        return args[0]
    return lambda f: f
```

### 4.4 SQLAlchemy execute 参数位置

**问题**：测试验证 `db.execute(text(sql), {"cutoff": cutoff})` 的参数传递时，`AssertionError: 'cutoff' not found in {}`。

**解决方案**：将测试中的 `kwargs["cutoff"]` 改为 `args[1]["cutoff"]`。

**中间件逻辑**：
```python
import uuid
import structlog
from starlette.middleware.base import BaseHTTPMiddleware

class RequestIDMiddleware(BaseHTTPMiddleware):
    async def dispatch(self, request, call_next):
        request_id = request.headers.get("X-Request-ID", uuid.uuid4().hex)
        structlog.contextvars.bind_contextvars(request_id=request_id)
        response = await call_next(request)
        response.headers["X-Request-ID"] = request_id
        structlog.contextvars.clear_contextvars()
        return response
```

export function highlightText(text: string, keyword: string): React.ReactNode {
  if (!keyword.trim()) return text;

## 四、关键设计决策（继承自前序计划）

| 决策点 | 选择 | 理由 |
|--------|------|------|
| D3-01 Token 存储 | CSP 策略（非 HttpOnly Cookie） | HttpOnly Cookie 需重构整个认证流程，CSP 有效降低 XSS 风险且不破坏现有架构 |
| D4-02 游标分页 | 可选 cursor 参数，向后兼容 | 不破坏现有 API 契约，前端可渐进迁移 |
| D5-04 暗色模式 | CSS 变量 + 核心页面 dark: 样式 | 全组件 dark: 改动量过大，CSS 变量让非核心页面自动适配 |
| D5-03 PWA | 手动 SW 注册（非 vite-plugin-pwa） | 避免新增依赖，保持构建配置简洁 |
| D1-01 分支模型 | DocumentFolder 独立表 + Document.folder_id 外键 | 比存 metadata_ JSON 更规范，支持外键约束和索引 |
| D10-01 审计日志 | 独立 audit_logs 表 + audit_service 统一服务 | 集中管理，便于查询和保留策略 |
